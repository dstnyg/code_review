# Hot 100 智能复习训练台

React + JavaScript + Vite 前端。原始 HTML 保留在上一级目录。

## 启动

安装 Node.js 22.12+（22.x）、24.x 或 26+，本项目已在 Node.js 24 下验证。在本目录运行：

```sh
npm install
npm run dev
```

访问终端显示的本地地址，默认是 http://127.0.0.1:5173。

```sh
npm test          # 题库完整性、排期、编辑与备份兼容测试
npm run build    # 生成 dist/
npm run preview  # 在 http://127.0.0.1:4173 预览构建结果
```

`dist/` 可部署到静态服务器，Hash 路由无需配置路径回退。请通过 HTTP 服务访问；不支持直接双击构建后的 HTML。依赖安装完成后，本地运行不需要网络，打开 LeetCode 链接需要网络。

## 旧记录迁移

1. 打开原始 HTML，在“设置与备份”中导出 JSON。
2. 打开新前端，在“设置与备份”中导入 JSON。
3. 核对新题、笔记、学习资料和练习记录。

保留 `lc_lab_hot100_v2` 存储键和 v3 备份结构，可导入原版备份及原始状态 JSON。localStorage 按来源隔离：协议、域名、端口或浏览器不同，都可能使用不同的存储。请固定访问地址，切换开发地址、预览地址或正式地址时通过导出／导入迁移。

导入和清空前先下载当前数据备份。损坏的原始存储不会被自动覆盖，可在设置中下载原始存储后恢复有效备份。

## 结构

```text
src/app/          页面布局、Hash 路由、Context + useReducer 状态
src/components/   题目卡片、学习面板、评级、编辑器等公共组件
src/pages/        总览、当天做题、复习、题库、分析、设置
src/data/         90 道原始题目及完整学习资料
src/domain/       日期、排期、评级、数据校验与编辑规则
src/storage/      localStorage 和 JSON 备份
src/styles/       全局样式，布局使用 CSS Modules
```

不执行用户粘贴的答案代码；答案、原始注释和笔记均作为文本展示。

复习规则：红色 +1 天、黄色 +3 天、不同日期连续绿色依次 +7／21／45 天。同一天只保留最终评级，红黄重置绿色次数；下次评级清除单次手动改期。统计只读取所选日期及之前的记录。

`scripts/extract-legacy.py` 是本次迁移的数据提取工具，会从上一级原始 HTML 重新生成 data 文件及基础规则；日常开发无需运行。原始题库与学习资料的逐字段一致性由测试校验。
